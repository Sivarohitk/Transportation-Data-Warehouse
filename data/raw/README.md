# Raw Source Folder

This folder stores the source-system flat files generated by `data/generator/generate_transport_data.py`.

Expected files:

- `carrier_lookup.csv`
- `locations.csv`
- `routes.csv`
- `shipments.csv`
- `daily_delivery_scan_events.csv`
- `delivery_exceptions.csv`
- `exception_code_lookup.csv`
- `route_distance_reference.csv`

These files are designed for SSIS flat-file ingestion and also align with the SQL Server `src` schema added under `sql/source`.
